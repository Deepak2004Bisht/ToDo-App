<h1>To-Do List App</h1>
<br>
The To-Do List App is a simple, user-friendly application designed to help users manage their daily tasks efficiently. This app provides an intuitive interface to add, edit, and delete tasks, making it easy to stay organized and productive.
<br>
<h2>Features</h2>
<br>
• Add Tasks: Users can quickly add new tasks by entering text in the input field and clicking the "Add" button.<br>
• Edit Tasks: Each task in the list has an "Edit" button (green). Clicking the "Edit" button allows users to modify the task.<br>
• Delete Tasks: A "Delete" button (red) is available for each task. Clicking this button removes the task from the list<br>
